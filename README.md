# TLC Image Analysis and Automation Tool
A MATLAB-based tool for analyzing thin-layer chromatography (TLC) images, measuring chromatographic spots, calculating retention factors (Rf), and exporting experimental data.

**Status:** In Progress

## Overview
Thin-layer chromatography is widely used in organic chemistry to monitor reactions and evaluate compound separation. This project explores how image processing and automation can make TLC analysis more quantitative, consistent, and efficient.
The application provides an interactive interface for analyzing TLC plate images and recording measurements.

## Features
- **Image Visualization:** Load and display TLC plate images for analysis.
- **Plate Measurement:** Interactively mark the baseline and solvent front.
- **Spot Detection:** Identify candidate chromatographic spots using image processing.
- **Manual Correction:** Add or adjust spots to improve measurement accuracy.
- **Rf Calculation:** Calculate retention factors based on spot positions, baseline, and solvent front.
- **Data Export:** Export measured spot positions and calculated Rf values to CSV files for further analysis.

## Technologies
- MATLAB
- Image Processing Toolbox
- Image processing and quantitative analysis
- Experimental data organization and CSV export

## Getting Started

### Requirements
- MATLAB
- Image Processing Toolbox for automatic spot detection

### Installation
1. Download or clone this repository.
2. Open MATLAB.
3. Navigate to the project directory.
4. Run the application by entering: matlab TLCVisionLab and pressing run
